Sages & inspiration

Wizard, Witch and Elven Sage use Quaternius’s Wizard, Witch and Elf from the Ultimate Animated Character Pack (2019), released under CC0. QUINTARC offers robe and trim colors, skin tones, hair colors where available, and original Sage hat, Horned helm, Tricorn or Crested helm, or no headgear; belts stay visible with four color choices. Existing characters keep their original Wizard selection. Original asset pack · License.

QUINTARC’s elemental invocation design is inspired by Invoker from Dota. QUINTARC is an independent game by Wobumii.

Studio & website artwork

The black-and-white Wobumii wordmark and W emblem are supplied studio artwork, used without altering the originals. The website uses a shared black-and-white brutalist theme. Game covers and portraits are displayed in monochrome while retaining their original source files.

The QUINTARC seal incorporates Open book by Lorc, CC BY 3.0, recolored and composed with five elemental orbs and symbols, surrounding rings, and a dark panel.

Visual inspiration: GitMastery. No reference website code or artwork was copied. Hosting: GitHub Pages.

Item and mob portraits are rendered from the games’ existing geometry and licensed source models. Project Pencil’s models and recipe shapes are original game artwork; QUINTARC portraits use the KayKit, Quaternius, Cethiel / Drummyfish, Heathal, Guillaume “GuieA_7” Englert, Poly by Google and Rock Golem resources credited above. Hole uses its in-game recipe symbol because it has no standalone mesh.
